Revenue

Retail Sales

Use for product sales, including artwork, merchandise, and other retail items sold through OAC.

Class / Workshop Revenue

Use for OAC-run onsite classes and workshops held at the shop.

Space Rental Revenue

Use for onsite classes or events where an outside artist or organizer is using OAC's space.

Offsite Event Revenue

Use for OAC events held away from the shop.

Service Charges / Fees Collected

Use for service charges or other fees collected from customers in addition to the primary sale.

Revenue Withheld for Processing Fees

Used when a selling platform withholds processing fees from revenue before the payout reaches OAC.

Discounts Given

Use for discounts, promotions, or reductions applied to customer sales.

Square Sales Tax Removed from Revenue

Used when separating sales tax collected through Square from revenue.

Direct Costs / Cost of Goods Sold

COGS - Class / Workshop / Event Supplies

Use this as the default category for general art materials and supplies used by OAC, including class, workshop, and event supplies.

COGS - Product Costs

Use this only when a purchase is clearly tied to products being sold, or when it comes from a vendor identified as consistently related to retail products. If you are unsure, use Class / Workshop / Event Supplies instead.

COGS - Vendor Payouts - Retail

Use for payouts to artists or vendors for products sold in the shop.

COGS - Teacher Payouts - Classes / Workshops

Use for payments to teachers or artists for onsite classes and workshops.

COGS - Event Labor

Use for contractors or help paid specifically for offsite events.

Simple supplies rule
Most art and material purchases can go to Class / Workshop / Event Supplies.
Default: COGS - Class / Workshop / Event Supplies Use for general art supplies, workshop materials, class materials, and event-related supplies unless the purchase is clearly retail-specific.
Exception: COGS - Product Costs Use only for purchases clearly tied to products being sold, or vendors identified as consistently related to retail product costs. If unsure, use Class / Workshop / Event Supplies.
Revenue and direct cost logic
Think about what happened in the business first.
Onsite OAC class or workshop Revenue: Class / Workshop Revenue
Teacher payment: COGS - Teacher Payouts - Classes / Workshops
Outside artist uses OAC space Revenue: Space Rental Revenue
OAC offsite event Revenue: Offsite Event Revenue
Event-specific help: COGS - Event Labor
Retail product sale Revenue: Retail Sales
Artist/vendor payout: COGS - Vendor Payouts - Retail
